# Solar-Powered Elevator System
This repository contains the technical documentation and simulation reports for a 20 kW solar photovoltaic elevator system equipped with a Battery Energy Storage System (BESS) and Emergency Rescue System (ERS).

## Project Highlights
-Total Peak Power Demand(P_peak): 20 kW (18 kW traction motor + 2 kW ancillary systems).
-Simulation Environment: Validated via MATLAB/Simulink and ETAP 2021 for load flow and short-circuit protection coordination.

-Key Features: 
High-speed contactless control topology, automated energy recovery, and continuous off-grid reliability during utility blackouts.

## Files
- Solar_Powered_Elevator_Technical: Comprehensive technical report detailing the system architecture, component sizing, and single-line diagrams.
